Protect your privacy on video

A service for automatically blurring faces in videos. Upload your clip and get the result in a couple of minutes. Safe, fast, and no complex settings

/ About project

This project was developed as part of the "Computer Graphics" course at HSE University (2nd year, CSE program)

  • Before starting development, I studied the general theory of computer graphics. I then moved on to the materials needed to build the service: I familiarized myself with the OpenCV library and subsequently with MediaPipe.

    Among MediaPipe's computer vision models, I chose Holistic — it accurately detects the face and its contours, and also gives access to hands, legs, and torso. This allows the project to be expanded with new features in the future.

  • Additionally, I already had a background in frontend and backend development. I was familiar with HTML, CSS, Go, Python, and had basic knowledge of JavaScript.

    During this project, I learned how to connect the frontend with the backend using JavaScript, and I figured out how to make a website responsive and interactive. I also studied FastAPI to implement the Python service.

/ solutions

Implementation approach

  • 01
    Python service

    Face-blurring service using OpenCV, MediaPipe, and NumPy with the Holistic model — it tracks facial contours accurately, even when the person moves.

    A function maps connected facial points — triangles between them, plus eye and lip contours — and all further logic uses these points.

  • 02
    Go service

    Built with Clean Architecture. Server runs in Docker. Metadata stored in PostgreSQL. Logging and middleware implemented. Connection pool, env variables, and Makefile set up.

  • 03
    Design

    I analyzed the format and design style for the service. To convey reliability, I chose rounded shapes and a dominant blue color. Then I created the wireframe, integrated text, refined details, and built the responsive versions.

  • 04
    Frontend

    Designed the website using HTML and CSS. I made an interactive in JavaScript and connected the frontend to the backend via JavaScript.
