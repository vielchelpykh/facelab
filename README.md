# ТЗ: MVP «Размытие лиц»

## Цель MVP

Работающее приложение: пользователь загружает видео → система размывает лица → пользователь скачивает результат.

---

## Python-часть (CV)

Что делает: обрабатывает видео, размывает лица.
Библиотеки: OpenCV, MediaPipe.
Функции:

1. Принимает путь к видеофайлу.
2. Читает видео покадрово.
3. Для каждого кадра определяет лица через MediaPipe.
4. Размывает найденные лица (GaussianBlur).
5. Записывает результат в новый видеофайл.
6. Возвращает путь к обработанному видео.

---

## Go-бекенд

Что делает: принимает видео от фронтенда, вызывает Python, отдает результат.
Библиотеки: gorilla/mux, os/exec.
Функции:

1. POST /api/v1/videos — принимает видео, сохраняет на диск, вызывает Python-скрипт.
2. GET /api/v1/videos/{id} — возвращает статус обработки.
3. GET /api/v1/videos/{id}/download — отдает готовое видео.

---

## Фронтенд

Что делает: интерфейс для загрузки и скачивания.
Технологии: HTML, CSS, JavaScript (Fetch API).
Страницы:

1. Главная: о проекте.
2. Страница для работы с видео: загрузка видео, плеер с обработанным видео, кнопка «Скачать».
