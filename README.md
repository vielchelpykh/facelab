# FaceLab — MVP «Размытие лиц»

Приложение для автоматического размытия лиц на видео. Пользователь загружает
видео, система находит лица через MediaPipe и размывает их (GaussianBlur),
после чего результат можно скачать.

## Цель MVP

Работающее приложение: пользователь загружает видео → система размывает лица → пользователь скачивает результат.

---

## Что не реализовано

В рамках MVP основная цель — загрузка видео, размытие лиц и скачивание
результата — выполнена. Часть элементов интерфейса осталась на уровне
вёрстки без рабочей логики из-за сжатых сроков и отсутствия времени на
освоение соответствующих технологий.

**Не реализовано:**

1. **Чекбоксы «глаза / рот / контуры» и ползунок силы размытия**
   на странице Blur. Элементы присутствуют в вёрстке, но не связаны
   с бэкендом. Сейчас размываются все лица целиком с фиксированной силой
   размытия.

2. **Страница Camera.** Функционал не реализован — доступ к камере
   и обработка потока в реальном времени отсутствуют.

3. **Форма обратной связи на главной странице.** Отправка данных не
   настроена, форма не обрабатывается.

4. **Смена языка интерфейса.** Переключатель присутствует, но логика
   локализации не реализована.

Все перечисленные пункты — задел на дальнейшее развитие проекта, а не
осознанный отказ от функциональности. При наличии времени они могут быть
доработаны поверх текущей архитектуры без существенных изменений.

## Архитектура

- **frontend** — HTML/CSS/JS, отдаётся через nginx на порту `3000`.
- **go-backend** — принимает видео, сохраняет его, вызывает Python, отдаёт
  результат. Порт `8080`.
- **python-service** — обрабатывает видео через OpenCV + MediaPipe, пишет
  результат на общий volume. Порт `8000`.
- **postgres** — хранит метаданные оригиналов и размытых видео.

Все сервисы общаются по внутренней сети `app-network`, видеофайлы лежат
в общем volume `shared_videos` (`/shared/original` и `/shared/blurred`).

---

## Python-часть (CV)

Что делает: обрабатывает видео, размывает лица.
Библиотеки: OpenCV, MediaPipe.
Функции:

1. Принимает путь к видеофайлу.
2. Читает видео покадрово.
3. Для каждого кадра определяет лица через MediaPipe.
4. Размывает найденные лица (GaussianBlur).
5. Записывает результат в новый видеофайл.
6. Возвращает путь к обработанному видео.

---

## Go-бекенд

Что делает: принимает видео от фронтенда, вызывает Python, отдает результат.
Библиотеки: gorilla/mux, os/exec.

Эндпоинты:

| Метод | Путь | Описание |
|-------|------|----------|
| POST  | `/api/v1/videos` | загрузить оригинал |
| PATCH | `/api/v1/videos` | запустить размытие |
| GET   | `/api/v1/videos/{id}/file` | скачать размытое видео |
---

## Фронтенд

Что делает: интерфейс для загрузки и скачивания.
Технологии: HTML, CSS, JavaScript (Fetch API).
Страницы:

1. Главная: о проекте.
2. Страница для работы с видео: загрузка видео, плеер с обработанным видео, кнопка «Скачать».

## Настройка окружения

Перед первым запуском создайте файл `.env` в корне проекта и заполните
переменные для PostgreSQL:

```env
POSTGRES_USER=test-user
POSTGRES_PASSWORD=secret
POSTGRES_DB=facelab
```

- `POSTGRES_USER` — имя пользователя БД
- `POSTGRES_PASSWORD` — пароль пользователя БД
- `POSTGRES_DB` — имя базы данных

Эти значения используются контейнерами `postgres`, `go-backend` и утилитой
миграций. Можно указать свои — главное, чтобы совпадали во всех сервисах
(они подставляются из `.env` автоматически при запуске через `make`).

## Как запустить

Требования:

- Docker и Docker Compose
- `make`
- Свободные порты `3000`, `8080`, `8000`, `5432`

Из корня проекта выполните:

```bash
make up
make migrate-up
```

После этого перейдите на страницу:

```
http://localhost:3000
```

Готово — можно загружать видео и размывать лица.
